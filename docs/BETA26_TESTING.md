# 草稿检查与恢复 / Draft recovery

编辑草稿与笔记正文分别保存。遇到无法读取的草稿时，可以先检查，再决定是否丢弃；这一操作不会删除原笔记。

## 无法读取草稿时

1. 打开有草稿提示的笔记，或从笔记的“更多”菜单进入草稿恢复。
2. 选择“检查草稿”。检查在后台进行，可以取消或稍后处理；检查本身不删除文件。
3. 检查通过后，应用会再次询问是否丢弃这份草稿及其恢复文件。确认后才开始清理。
4. 如果草稿在检查后发生变化，旧确认会失效。重新打开草稿恢复入口，再检查当前内容。

清理期间会显示相应状态，同一笔记的文字编辑会等待清理结束。离开页面会取消尚未提交的检查；已经进入删除阶段的操作会按顺序完成。

检查有本地大小与时间预算。超出范围、超时或无法验证时，文件会保留，并显示具体原因。这不意味着任意大小的损坏文件都能在应用内清理。

正常编辑、继续草稿和取消编辑的说明见[文字编辑指南](BETA24_TESTING.md)。PDF 分享说明见[PDF 指南](BETA25_TESTING.md)。

## When a saved draft cannot be read

Editing drafts are stored separately from the note itself. You can inspect an unreadable draft before deciding whether to discard it. The original note stays intact.

1. Open the note with the draft notice, or use draft recovery from the note's **More** menu.
2. Choose **Check draft**. Inspection runs in the background and can be cancelled or deferred. Inspection alone does not delete files.
3. A completed check opens a separate confirmation. Confirming it discards that draft and its recovery files.
4. If the draft changes after inspection, the old confirmation expires. Open draft recovery again to inspect the current files.

Cleanup has its own status. Text editing in the same note waits for cleanup to finish. Leaving the page cancels work that has not reached deletion; deletion already in progress finishes in order.

Local inspection has size and time budgets. If a limit is reached or verification fails, the files remain on the device and the app explains the result. Arbitrarily large damaged files are not guaranteed to be removable in the app.

Downloads and issue reports are available from the [PadNote repository](https://github.com/shiyan688/padnote). When reporting a problem, include the device, steps and displayed error; keep private notes and credentials out of the report.
