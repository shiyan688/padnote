# beta.23 纸面与导入检查

本指南帮助你检查升级后的纸面与导入流程。Android 安装包名为 `PadNote-Android-0.18.0-beta.23-debug.apk`。Windows 连接助手沿用 beta.20 的 Setup 与 Portable 包；它们不包含 Hermes、模型或 API 密钥。现有三个演示视频仍展示此前版本/素材，不是 beta.23 新录制。

升级时请保留原应用和笔记。不要卸载应用或清除数据来排查问题。

## 检查步骤

1. **文字放置与取消：**打开自建测试笔记，在工具栏选择 **文字笔：点击页面插入**。按下后拖动或取消；未确认落点不应创建文本框，完成点击后才放置文字。
2. **文字手势：**保持文字工具，在空白处双指缩放，先抬起一根手指继续移动，再全部抬起；不应新建文本框。随后选中已有文字，再双指缩放，检查原文字与位置没有被误改。
3. **多页混排：**用较长的表格和普通段落创建测试笔记。检查表格续页是否重复表头、单元格文字是否完整，已有笔记内容是否保持不变。遇到分页或内容异常，停止编辑并记录页面位置。
4. **旧笔记导入：**导入旧版 `.padnote`。若提示图片超出页面范围，导入应被拒绝，书架不应留下打不开的条目。可返回并修正文件后重试；不要通过删除应用数据处理。
5. **PDF 准备：**选择 **导出笔记** → **标准 PDF（页面已合并）**。若当前内容无法准备 PDF，应用应先提示无法继续，不应提前打开系统保存器。修正内容后可以重试。
6. **分享与 Agent：**使用 **分享/Agent**，选择 **分享当前纸面 PDF…** 或 **交给电脑 Agent…**。这两个操作处理当前笔记的全部页面，不是套索选区；发送前检查笔记内容、标题和页数。遇到明确失败提示时返回纸面或重试；结果状态不确定时不要重复提交。

表格若包含当前规则无法安全拆分的受保护格式，应用会保留原文并提示手动缩短或拆分；PDF 导出也会说明无法继续。此时不要反复提交，先在原文中调整表格再试。

## 报告问题

请记录应用版本、设备型号、当前工具名称、操作步骤、页面位置和屏幕提示。只使用合成测试笔记；不要附上密钥、配对令牌、密码、私人笔记或设备标识符。
