# 视角恢复与连接引导

## Android：回到刚才看到的位置

用一份可丢弃的笔记检查：

1. 写一段正文并完成编辑，移动到另一页，再缩放到便于阅读的大小。
2. 返回书架，重新打开这份笔记，查看页码、缩放和页面位置。
3. 调整窗口大小或旋转屏幕，再返回书架重开；确认正文、笔迹和页数完整，视角没有跳回更早的位置。
4. 修改一段正文，完成后立即移动页面，再打开“分享 / Agent”。应能进入材料预览；发送仍需要单独确认。
5. 切到其他应用再回来，重开笔记，检查最近的浏览位置。

浏览位置是当前设备的阅读设置，不计作一次正文修改。换设备或恢复备份时，没有本机位置记录的笔记会使用笔记文件中已有的视角。位置记录损坏时应回退到该视角，不能因此打不开正文。

## 电脑助手：找到正确的配置入口

如果显示“常见位置未找到 Hermes”，它表示助手没有在支持的位置找到安装；Hermes 可能已经在 WSL 或其他目录中。点击“手动填写可访问的本机 API 地址”，可以直接展开 Hermes 配置表单。

如果显示“发现多个 Hermes 配置”，点击“查看已发现的 Hermes 配置”，应展开列表并显示“使用此配置”按钮。在这里选择要连接的配置，再检测接口和配对平板。

使用键盘时，这两个入口都应能通过 Tab 找到并按 Enter 打开；窗口变窄时，说明和入口应换行，主要操作保持可见。

本轮没有增加 WSL 自动发现或改变 Agent 执行协议。安装器验收、设备测试与真实 Agent 往返均需各自的运行证据；编译成功不能代替这些检查。
