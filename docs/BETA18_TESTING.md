# PadNote beta.18 测试指南

## Android：PDF 任务交接

本版调整任务状态提示、只读后台刷新、任务入口与收件人显示。现场曾有任务停留在发送中；这次更新不代表已确认该次问题根因，也不代表原 PDF 已送达电脑。

1. 在现有 PadNote 上直接覆盖安装 beta.18，不要卸载。若有一直显示“发送中”的旧任务，打开原笔记并先点“复制诊断”；暂不重试或重新发送。首轮诊断可发回当前支持对话，不要附原始 PDF、令牌或密钥。
2. 需要继续验证时，再创建新任务并选择已配对的电脑 Agent，观察任务状态提示。
3. 提交后可返回笔记或离开页面，稍后再查看任务。任务处理可能需要电脑端时间；结果不确定时不会自动重复提交。
4. 若仍未更新，复制诊断并记录发生时间、页面提示与电脑端 Agent 状态。

本次合成 PDF 已交给 Windows 助手，但上游提交确认请求超时，未取得上游 run ID，因此无法确认 Hermes 是否创建或执行了 run。此前现场卡住任务的原因仍未确认。

## Windows：beta.18 连接助手

创建 Hermes run 时，助手先返回本地任务回执，再在后台等待响应，最长 45 秒；其他请求仍为 10 秒。任务查询会先显示提交中状态，关闭窗口时最多等待 60 秒；未知结果不会在重启后自动重放。

升级前停止连接助手并关闭窗口，再运行 beta.18 安装包。升级会保留配对状态与 TLS 身份。beta.18 R2 已在 Windows 原位升级验收：配对身份与已有任务均保留；22 项连接助手测试通过。使用 `SHA256SUMS.txt` 校验下载文件；安装版与便携版均为 Windows x64。
