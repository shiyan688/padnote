# beta.20 使用与测试

Android 与 Windows 连接助手建议同时更新。普通任务提交和查询仍可使用旧客户端；新版电脑助手的停止与审批要求支持操作收据的新版平板，旧版会收到明确升级提示。

## 在纸面上开始

打开笔记，点击 AI 按钮。没有选区时，按引导先用套索圈选，或配置自己的模型。选取范围经确认后发送；打开引导不会自动发送整页或修改笔记。新建文字默认为正文，公式有单独入口。

使用“分享/Agent”导出完整纸面 PDF，或选择已配对且支持纸面任务的 Hermes。发送后可返回笔记，在电脑任务列表跟踪状态。配对完成和 Agent 就绪分别显示。

## 停止与审批

请求先保存到电脑，再在后台发送；“停止中”表示仍在确认，不能当作已经取消。明确未发送或被拒绝时可再次操作；结果未知时继续查看状态，不自动重复发送审批。

审批须绑定当前请求 ID 和执行代数，且有可读的操作内容。旧 Hermes API 或只有标题、缺少操作内容的审批，请在电脑端处理或更新 Hermes；界面不会提供一个含义不明的批准按钮。新协议不扩大“仅此次/拒绝”权限。

## 反馈时附什么

记录设备与版本、操作步骤、界面提示和任务诊断。不要发送 API Key、配对令牌、密码或私人笔记。结果未知的任务保留原任务 ID，不另建一条重复任务来“试一试”。

Android APK 保留 beta 包名与原签名，可覆盖更新；不要卸载或清除资料。Windows 提供 Setup 与 Portable。iPad 提供 Xcode 源码，暂无签名 IPA。
