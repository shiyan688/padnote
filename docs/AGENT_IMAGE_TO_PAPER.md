# 把 Agent 图像放回纸面

在任务结果中，只有 Bridge 任务已完成并列出 PNG/JPEG 文件时才会出现“放到纸面”。选择目标笔记后，先查看纸面预览中的图像位置和与现有内容的重叠，再决定是否确认；若选择重叠位置，需明确确认。现有内容不会被移动或删除。取消预览不会改动笔记。保存成功后可从原任务再次打开对应笔记。

发给 Agent 的画图要求可以写成：“根据纸面公式先判断条件是否足够；若定义域或其他条件不足，请说明并画一条可代回验证的示例曲线。输出 PNG，标出坐标轴和关键点。”

放置前，PadNote 会校验任务附件身份、原始大小和 SHA-256，检查 PNG/JPEG 类型并将图片转换成笔记使用的 PNG 格式。没有文件、任务仍在运行、结果待确认、下载或解码失败时，不会显示放置成功。

Agent 图像只有在用户确认放置后才写入笔记。普通笔记继续使用 schema 10；首次确认插入时才升级到 schema 11。切换排版不会降回旧 schema。确认前会提示：较旧的 PadNote 版本不支持 schema 11，无法打开这份笔记。该图像及其来源记录保存在笔记正文中，随笔记备份；连接地址、访问令牌和临时文件路径不会写入来源记录。

图像插入目前仅接受 PNG 和 JPEG。WebP 与 SVG 不支持放置到纸面；PDF 保持文档附件用途，不作为纸面图像放置。
