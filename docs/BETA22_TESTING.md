# beta.22 纸面手势

本次更新 Android 纸面导航，Windows 连接助手继续使用 beta.20。APK 保留原 beta 包名与签名，覆盖更新可保留资料；不要卸载或清除应用数据。

## 先试这两个变化

1. **长文首页缩放**：打开多页长文，在首页附近缩小再放大。首页允许保持居中，缩放不再因旧的顶部边界被强拉到下一页。靠近纸面边界时仍有合法滚动范围，并不承诺任何位置都可无限平移。
2. **选中文字后缩放**：先用套索选中文字，再用两个手指平移/缩放。两指可落在同一段文字、不同片段、文字与空白处；第二指加入会取消尚未提交的文字拖动或尺寸预览，不应误移动文字。

单指仍可操作选中的文字流，边缘和角部控制点调整大小，双击编辑。文字流跨页时，移动、字号和删除作用于整条文字流；AI 初始图片则只取已选中的当前页片段，见 [选区范围](AI_PAPER_SELECTION.md)。

正在输入的编辑框保留原有文字编辑手势；触控笔、橡皮或鼠标混合输入不作为纯双指导航接管。底部添加新页的阻尼和确认规则保持。

## 其他功能

继续支持文字、笔迹、图片和 PDF 合成 AI 选区；先检查预览，再用自己的模型配置发送。电脑任务的后台提交、停止与审批收据见 [beta.20 指南](BETA20_TESTING.md)，文字选区说明见 [beta.21 指南](BETA21_TESTING.md)。

README 的纸面视频和 PDF 展示仍是已有合成素材，并非 beta.22 手势的新录屏。iPad 本轮未改代码，暂无签名 IPA。

## 验证与反馈

这两项原问题已在自建长文上真实复现；修复后的设备执行状态与构建结果分别记录，不把测试 APK 编译当作设备运行通过。新增回归覆盖顶部边界、实际捏合计算和文字浮层的完整事件流。

反馈请提供设备与版本、手势从哪里开始、当前工具/文字是否选中、实际页码和缩放比例。只使用可公开的测试笔记；不要提交密钥、配对令牌或私人资料。未知的电脑任务仍保留原 ID，不重复发送。
