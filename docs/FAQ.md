# PadNote 常见问题

## 现在能下载安装吗？

Android 可以下载 [beta.13 APK](https://github.com/shiyan688/padnote/releases/tag/v0.18.0-beta.13)，需要 Android 7.0 / API 24 或更新版本。这是调试签名测试版。iPad 有源码，需要 Xcode 构建并自行签名；没有可安装的签名 IPA。新首用界面目前只是源码修改，尚未进入公开 APK。

## 第一次应该做什么？

新建笔记写几行，或导入 PDF；用套索圈选一小段，打开 AI，配置图像模型，然后选择讲解和是否允许写入。完整步骤见[快速指南](QUICK_START.md)。

## 必须装电脑 Agent 或 Windows 助手吗？

不需要。普通书写和通过模型 API 讲解都不需要电脑 Agent。Hermes 与连接助手属于可选的纸面任务交接流程；OpenClaw 当前提供发现和设置引导，Codex 纸面任务尚未接入。

## 免费吗？模型费用谁收？

客户端自研代码开源。普通本地书写不调用模型；AI 需要你自己的服务、密钥和可用额度，费用取决于服务商。预设名称不是免费承诺。保存配置不会请求模型；发送、重试和多轮工具调用可能产生费用。

## 用什么模型？

首次可用支持图像输入的 OpenAI-compatible HTTPS 服务，选择直连多模态并填写服务商实际地址、模型名及密钥。也有转写与回答分开的两段式模式。“兼容”不保证图像、工具调用或所有参数都可用，请用一小段材料确认实际行为。

## 模型会读取我的所有笔记吗？

Android 默认请求使用选区图片、问题/当前会话上下文及不含正文的布局地图。知识库额外材料需要明确选择；“允许写入”不等于允许读取所有笔记。更换材料或接收配置会重建发送上下文。发送前请核对预览，完整规则见 [AI_READ_SCOPE.md](AI_READ_SCOPE.md)。这不代表模型调用完全留在本机。

## 能离线用吗？会自动云同步吗？

本地书写和笔记可离线使用，AI 需要配置的服务。笔记默认保存在设备，没有自动云同步。跨设备可手动导入导出；单本笔记包与整库备份的范围不同。

## 回答一定会自动写在纸上吗？

取决于本轮写入权限及模型实际行为。“仅卡片”只展示回答；“允许写入”允许模型调用笔记工具。兼容回退会显示提示。检查实际落点和内容，PDF 笔记的 AI 写入位于空白附注页。模型工具不能修改手写笔迹。

## 取消会退费吗？

不会作此保证。应用可使本地回调失效并取消本地 HTTP 等待，服务商仍可能已处理请求或计费。已执行的笔记操作不会因取消自动回滚；工具开始后也不会整轮重放。见[请求生命周期](AI_REQUEST_LIFECYCLE.md)。

## 已经在真机和真实模型上验证了吗？

beta.13 文档记录 329 项 JVM 测试和 Android API 35 模拟器界面检查；该轮未连接实体平板、真实模型或真实 Agent。此次首用改善没有新增真机验收或发布 APK。请分别阅读 [beta.13 测试范围](BETA13_TESTING.md)和[本轮源码检查](FIRST_USE_VALIDATION.md)，不要把单元测试当成触笔体验或模型质量保证。
