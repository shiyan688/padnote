# beta.21 使用与测试

这次更新 Android 的 AI 纸面选区，Windows 连接助手继续使用 beta.20。APK 保留原 beta 包名与签名，可覆盖更新；保留原笔记与配对，不要卸载或清除应用资料。

## 从选中文字开始

1. 在纸面选择当前页的一段文字，或用套索圈出要讨论的文字、笔迹、图片和 PDF 内容。
2. 点 AI，等待选区预览。准备期间可取消；跨页圈选会提示在单页内重选。
3. 检查预览包含所需内容，使用自己的模型配置，确认后再发送问题。

选择长文中的一个片段不会自动上传整条文字流。矩形文字选区包含周围少量纸面，套索范围外的像素被遮罩。预览和发送使用同一张图片。具体范围见 [AI 纸面选区](AI_PAPER_SELECTION.md)。

## 建议尝试

- 只有文字的笔记：选中文字后打开 AI，确认预览里有文字。
- 混合纸面：圈选文字与手写批注，确认它们在同一张预览中。
- 多页长文：只选当前页片段，确认相邻页没有进入预览。
- 取消准备后重新选择；切换笔记后不要出现旧选区结果。
- 导出标准 PDF，核对末页与原纸面。PDF 当前为扁平化页面，正文不保留为可搜索文本。

电脑任务仍支持后台提交与操作收据，见 [beta.20 指南](BETA20_TESTING.md)。本轮没有更改 Windows 执行程序或 iPad 代码。

## 验证记录

Android 在 h1003 完成 JVM、lint、主 APK 与测试 APK 编译。新增设备测试覆盖文字片段、单页范围、遮罩和取消资源所有权；设备执行状态与构建结果分别记录，不以编译替代设备验收。

真实平板使用合成 36 段双语长文，保存、缩放、重开后原文与 18 页页数保持；实际 PDF 的段落标号和首尾标记完整。首、中、末页抽查无裁切。该验证使用与 beta.20 核心纸面代码一致的已安装 beta.17，不当作 beta.21 新选区界面的验收。
