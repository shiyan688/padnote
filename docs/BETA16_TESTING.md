# Windows beta.16 使用说明

## 更新与首次连接

1. 更新前在旧助手中停止服务并关闭窗口，再运行 beta.16 安装程序；现有配对与设置会保留。
2. 打开助手，选择“检查并启动”，检查发现的 Hermes 实例并按需绑定。
3. 在连接教程中选择 Agent，生成二维码并用 PadNote 平板扫码，按电脑端提示批准设备。
4. 若没有 Hermes，可从助手显示的固定版本官方安装脚本入口查看来源并在可见窗口确认。安装后仍需完成 API/服务配置与模型登录；模型供应商由用户自行选择。

## beta.16 改动

- 助手尚未启动时，可一键启动并连接 Hermes。
- 保留 beta.15 已开始任务的上游运行 ID 关联；结果未知时先查询原任务，无 ID 的不确定提交不会自动重发。
- 保留已有 Hermes 发现/绑定、首次连接教程和固定官方安装脚本的可见入口。

Android 继续使用 beta.13。本说明记录功能和操作步骤，不代表全新 Hermes 安装、API 自动配置、延迟归因或可视 GUI 的实机验收。
