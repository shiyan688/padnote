# PadNote 设计语言（Design Language / Taste Rules）

> 本文档是给人和 AI 共同执行的审美契约：改任何界面之前先读这里；这里的规则
> 都带「为什么」，覆盖不到的新情况应从这些理由出发推断，而不是凭感觉发明。
> 每轮 UI 工作结束前对照末尾的 De-slop 清单自查。

## Taste Brief（方向，不是风格清单）

- **用户**：用平板+手写笔做学术工作的人——数学笔记、论文推导、长文档阅读。
  重度公式、长时间注视、效率敏感、讨厌花哨。
- **核心任务**：书写 → 圈选问 AI → 数字化为可检索知识库。界面为这三个任务服务，
  其他一切退后。
- **三个感觉**：
  1. **安静的纸面工作台**——像一张整理好的书桌，不像 SaaS 营销页；
  2. **工程仪器般的克制**——信息密度可以高，装饰必须低；每个像素都有职责；
  3. **文具的真实感**——暖纸底、墨水色，材质感来自颜色而不是阴影和渐变。
- **Reference**：GoodNotes 的纸张质感、Linear 的密度与安静、Notion 的排版层级。
- **Anti-reference**（看到就删）：紫蓝渐变、玻璃拟态、emoji 当图标、大投影卡片阵、
  居中大 Hero、"Transform your workflow" 式文案、无意义的 badge 和 pill 堆砌。

## 令牌（Tokens）——只允许从这里取值

代码中对应 `MainActivity` 顶部的常量区；Android 侧同步维护 `styles.xml` 的
`colorAccent`。新增颜色/圆角/字号前先问：现有令牌真的不够吗？

| 类别 | 令牌 | 值 | 用途 |
| --- | --- | --- | --- |
| 底色 | SURFACE | `#F4F1E8` 暖纸 | 窗口背景 |
| 卡面 | CARD | `#FFFFFF` + 发丝描边 `#ECE9E2` | 可点击对象容器 |
| 主色 | ACCENT | 书写蓝 `#285EA8`，浅底 `#E8F0FA` | 唯一强调色：主按钮、选中态 |
| 知识库 | VAULT | 墨绿 `#2F805B`，浅底 `#E9F3EE` | 只标记知识库域 |
| 警示 | AMBER | 字 `#A46A2A`，底 `#FAF2E6` | 过期提醒、隐私提示 |
| 危险 | DANGER | 红 `#B23A30`，底 `#FAEEEC` | 删除类 |
| 文字 | INK / SECONDARY / FAINT | `#1F2933` / `#6B7684` / `#89939B` | 三级层级，禁止第四级灰 |
| 圆角 | radius | 卡 20 / 行卡 18 / 控件 19 / 徽章 9–10 | 不出现其他值 |
| 间距 | spacing | 4 的倍数；页面水平边距 24dp 统一 | 层级靠间距，不靠线框 |

## 规则（每条都回答为什么）

### 层级与构图
1. **层级靠字重、字阶和间距表达，不靠描边、阴影和底色堆叠。**
   为什么：线框和阴影是最容易滥用的强调手段，叠起来就是"AI 味"。
2. **一屏只有一个实心主按钮**（PRIMARY）。次级动作用 TONAL，三级用 QUIET 文字按钮。
   为什么：主按钮是视觉重心，多于一个就没有重心。
3. **卡片只给"可点击的对象"用**（笔记、格式笔记条目）。引导文案、说明文字用
   平铺色板或裸文本，不要包白卡。为什么：卡片是点击的邀请，包住静态内容会
   制造假的交互暗示。
4. **分区标题 = 粗体标题 + 一行灰色说明（或计数）**，不加图标、不加分割线。
   为什么：中文界面里装饰性小图标是噪音源；说明文字承担信息量。
5. **禁止 emoji 作为功能图标。** 为什么：渲染随设备字体漂移、风格不可控、
   且是当前最典型的 AI slop 信号；需要图形时用文字徽章（01/02/03、MD、⋮）或自绘。

### 排版
6. 字阶只有五档：28 页面标题 / 17 区块标题 / 15 条目标题 / 13–14 正文 /
   11–12 说明。为什么：字阶即层级，第五档之外的出现说明层级设计失败了。
7. 元信息（页数、时间、模型名）一律 SECONDARY 12sp；警示语义才允许 AMBER。
8. 中英混排不加字距技巧，靠字号和颜色分层。

### 交互与动效
9. **按压反馈必须有且即时**：所有可点击卡片和自绘按钮带 bounded ripple
   （前景层），按下立刻可见。为什么：默认 Button 的涟漪会被自定义背景杀掉，
   丢掉反馈的界面显得"死"，这是用户说不出但能感觉到的部分。
10. 高频操作不做入场动画（书架每次返回都重绘，任何 fade/scale 都是延迟）。
    Novelty 是调味料：一轮 UI 里新增的动效不应超过一处。
11. 触控目标 ≥ 40dp；⋮ 类溢出按钮 44dp 见方。为什么：笔和手指并用，误触代价高。

### 组件策略
12. 新组件先问"能不能用现有令牌+布局拼出来"。PadNote 已有：`pillButton` 四态、
    `cardSurface`、`guideStep`、`sectionCaption`、chip（程序化 GradientDrawable）。
13. 对话框自定义视图沿用卡面令牌；`colorAccent` 决定系统按钮颜色，不得单独改。
14. 文案具体、克制：写"整本变成 Obsidian 兼容 Markdown"，不写"解锁知识管理新体验"。
    提示语给出真实问法示例（如「我之前哪本笔记讲过…」）。

## De-slop 清单（每轮 UI 收工前过一遍）

- [ ] 有没有新增第四种灰色？→ 并入三级文字
- [ ] 有没有非令牌圆角/间距？→ 归入刻度
- [ ] 实心主按钮超过一个？→ 降级为 TONAL/QUIET
- [ ] 静态内容被包进了白卡？→ 改平铺色板
- [ ] 出现 emoji/装饰性图标？→ 换文字徽章或删除
- [ ] 层级靠描边+阴影叠加？→ 改字阶和间距
- [ ] 可点元素缺按压反馈？→ 补 `applyPressFeedback`
- [ ] 新增动画？→ 说明理由，否则删
- [ ] 文案抽象空泛？→ 改成具体动作和示例
