# PDF 导入与批注

书架或编辑器中的“导入笔记”现在接受 PDF、旧版 PadNote JSON，以及包含 PDF 的 `.padnote.zip`。

- 导入 PDF 会创建一本新笔记，原文复制到应用私有目录，不依赖原文件位置或临时授权。
- 每张 PDF 页面作为只读底图，可以在其上手写批注；橡皮擦只擦批注，不改原 PDF。
- 套索可直接圈 PDF 原文，无需先写一笔；发送给 AI 的图片包含圈内原文和选中的笔迹。
- AI 自动写入如果指向 PDF 原页，改为新增空白附注页，防止遮盖原文。用户仍可手动移动文字对象。
- 保存和重新打开保留原文与批注。导出 PDF 笔记得到 ZIP 包（note.json + source.pdf），可在另一台设备导入；普通笔记仍导出 JSON。
- 当前不输出“批注合并后的标准 PDF”，也不支持编辑原 PDF 文字、PDF 文本搜索或 EPUB。

资源范围：PDF 最大 100 MB、1–500 页。使用系统 PdfRenderer，不新增 PDF 库；单工作线程按需渲染，位图长边 1600 像素，最多缓存 3 页。原 PDF 保持原样，深度放大时显示清晰度暂受位图分辨率限制。混合尺寸页面按第一页比例的画布等比居中，不拉伸。

密码保护/不受系统支持的 PDF 会报告导入失败；请先解锁并另存。图表 Beta 与 PDF 能力独立，主分支同样支持 PDF。

验证：JVM 测试覆盖旧 JSON 往返、复制大小限制、缺失 PDF 和 ZIP 路径拒绝；PdfImportTest 设备测试覆盖真实 PDF 生成、圈选截图和 ZIP 往返。设备测试需要可用 Android 设备，编译通过不等于已运行。
