# PDF 页面尺寸与草稿保存

本次 Android 更新调整了 PDF 的纸张尺寸，并减少编辑草稿的重复写盘。导出不会改写笔记中的纸面、文字、笔迹或分页。

## PDF 会用什么纸张

- **A4 比例笔记：**导出为 A4；横向纸面使用横向 A4。
- **屏幕比例与旧格式笔记：**保留原有长宽比，页面大小限制在 A4 的外框以内。内容不会被拉伸或裁切，PDF 页面不一定是标准 A4。
- **带 PDF 背景的笔记：**采用源 PDF 第一页的显示尺寸，作为整本笔记统一的导出页面。原文件各页尺寸不同时，背景仍按比例放入笔记的页框。原 PDF 文件不会被修改。

纸张尺寸与图像清晰度分别处理。PDF 仍是纸面的图像导出，不提供可搜索或复制的文字层。

## 可以这样检查

1. 导出一份 A4 比例笔记，在阅读器的文档属性或打印预览中检查纸张与方向。
2. 导出一份屏幕比例笔记，确认文字、手写和图片完整，圆形与图表没有变形。
3. 对带 PDF 背景的多页笔记重复检查，并核对首页和末页。
4. 返回笔记，对照导出前的文字、笔迹、页数和位置。
5. 编辑一段文字后切换页面或应用，再打开笔记，检查已保存草稿能否继续编辑。相同草稿重复触发保存时，不会重复写盘；这不是逐键自动保存。

如果页面尺寸超出支持范围，应用会在打开系统保存器前提示。请保留原文件，尝试尺寸较小的 PDF 副本；若仍失败，可在 [GitHub Issues](https://github.com/shiyan688/padnote/issues) 提供设备、步骤与错误文字，不要上传私人笔记或密钥。

下载始终从[仓库的 Releases 页面](https://github.com/shiyan688/padnote/releases)进入。手动文字编辑和草稿恢复的详细说明见[文字编辑指南](BETA24_TESTING.md)。
