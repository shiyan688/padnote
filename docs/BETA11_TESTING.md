# PadNote 0.18.0-beta.11 测试指引

本次改进：Android 的模型、Agent、导出等选择菜单统一纸面风格；Windows 连接助手提供可直接安装的 setup.exe。

## Android

将 `PadNote-Android-0.18.0-beta.11-debug.apk` 下载到平板，直接覆盖安装已有 beta 版本即可。保持已有应用和数据，不要先卸载。

重点试这几处：
- 模型与 Agent 的选择、切换和保存，关闭设置后重新打开核对选中项。
- 导出、发送任务、任务预设和视频风格选项；确认文字可读、长选项能换行。
- 展开下拉框后按返回，确认关闭菜单，没有误触执行任务。
- 若系统使用大字号，检查选项是否完整可读；仍按你原来的流程写画、对话、分享和发送到电脑。

## Windows 10/11 x64

双击 `PadNote-Connection-Assistant-0.18.0-beta.11-Setup-x64.exe`，按安装程序完成安装。从开始菜单打开 PadNote Connection Assistant，点击“启动”，状态就绪后点击“打开管理页面”。无需为这个助手额外安装 Python 或 WSL。

平板与电脑连接同一 Wi-Fi；在管理页面添加或核对已有 Agent，然后用平板的连接入口扫描配对二维码并在电脑授权。无法连接时，确认 Windows 的网络类别是“专用网络”，再点击助手里的“允许同一 Wi-Fi 设备连接”；这个按钮会请求 Windows 管理员授权，仅开放本地子网的连接端口。

你的 Hermes 在 WSL 中运行。当前原生助手不会自动扫描 WSL 的配置；请先确保 Hermes 提供的服务地址可以从 Windows 访问，再在管理页面手动配置。仅在 WSL 终端能聊天并不等于已经开启了可连接的 Agent API。

安装和卸载保留 `%USERPROFILE%\.local\share\padnote-connection-assistant` 中的数据。安装程序是未签名测试版；Windows 可能提示未知发布者。已在 Windows 11 上通过 SSH 验证安装、原生窗口按钮启动与停止、就绪状态、管理服务、同版本覆盖安装和卸载；合成数据在重装和卸载后保留。普通桌面的显示与鼠标操作、实际同 Wi-Fi 配对仍需你测试。启动失败时反馈状态文字或这个数据目录中的 `launcher.log`，反馈前去除私人地址和敏感信息。

检查模型、Agent、导出、任务预设和视频风格菜单：切换并保存后重新打开，确认选中项；展开后按返回，确认只关闭菜单；使用大字号检查长标签换行与触控范围。
