# Android beta.17 任务发送测试指南

本版调整从 PadNote 笔记向电脑 Agent 发送 PDF 任务时的中间选择与状态呈现。此前现场曾出现卡片显示发送中；这次改动不等于已确认其根因，也不代表那份 PDF 已到达电脑。

## 覆盖安装与查看旧任务

1. 请在现有 PadNote 上直接覆盖安装 beta.17，不要先卸载。打开原笔记和一直显示“发送中”的旧 PDF 任务，先使用“复制诊断”保存状态；先不要点重试或重新发送。可将首轮诊断发回当前支持对话，无需公开原始 PDF、密钥或连接令牌。
2. 需要继续验证时，再从笔记发起一个新任务，在内置卡片中选择电脑 Agent。观察连接、上传与电脑处理等阶段提示。
3. 新任务提交后可以返回笔记或离开当前页面；页面关闭不会取消后台发送。可稍后回到任务查看状态。
4. 若仍在处理中，先查看电脑端 Hermes/Agent 是否仍在工作，再复制诊断供排查。结果未知时不会自动重发；不要仅因状态未刷新就重复提交。

任务处理可能需要电脑端时间。记录复现步骤、显示阶段和诊断摘要即可。
