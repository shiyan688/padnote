# 第一份 PadNote 学习笔记

目标是完成一次“写或导入 → 圈选 → 配置模型 → 讲解 → 保留笔记”。先用一小段你愿意交给模型服务处理的材料。普通书写不需要 API Key；电脑 Agent、Windows 助手和视频功能都不是这条流程的前提。

## 1. 安装并准备一小段材料

从 [Android beta.13 Release](https://github.com/shiyan688/padnote/releases/tag/v0.18.0-beta.13) 下载 APK，核对随包 SHA256SUMS。需要 Android 7.0 或更新版本；这是调试签名测试版。覆盖安装前备份笔记。

在书架点“新建笔记”，写几行文字或一个简单推导。已有讲义时点“导入笔记”，选择 PDF；导入会创建新笔记，可在原文上批注。也支持 PadNote JSON 和含 PDF 的可编辑包。iPad 目前只有源码，没有可直接安装的签名 IPA。

## 2. 圈选需要讲解的部分

点套索，圈一小块内容，再点 AI。PDF 原文可直接圈选，不必先写一笔。检查 AI 卡片中的选区图片：是否清楚、是否包含你要问的内容。若已经有旧会话，按提示选择继续旧材料或使用当前圈选。

## 3. 配置你自己的模型

公开 beta.13 的路径是 **AI 卡片 → 设置 → 新建配置**。

- 配置名称：取一个自己能辨认的名字。
- 路线：首次可选“直连多模态”，一个模型看图并回答。
- API 地址：使用服务商提供的 HTTPS 基址或完整 Chat Completions 地址。
- 模型：必须支持图像输入，名称按服务商实际文档填写。
- API Key：使用该服务商账户的有效密钥。

预设是可编辑建议，不保证该模型今天仍可用、免费或支持笔记工具。服务商可能按请求收费；PadNote 不附送额度。保存配置后返回 AI 卡片；首次发送仍会显示材料和接收地址确认。

当前源码把第一次配置改为直接打开配置表单，并支持滚动查看字段；这部分尚未发布到 beta.13 APK。

## 4. 讲解并决定是否写入

希望回答留在纸面时，先选“允许写入”，再点“讲解”。只想读回答时选“仅卡片”。确认发送预览里的选区和接收地址；额外材料默认未选，不需要先建立知识库。

“允许写入”是授权，不保证模型一定调用写入工具。检查实际结果和界面提示：回答可能只在卡片中，兼容回退也会提示。PDF 笔记的 AI 自动写入使用空白附注页。模型可能认错手写或推理出错，重要结论请自行核对。

## 5. 保存，再继续提问

使用“立即保存”，或返回书架并检查保存状态，再重新打开笔记确认内容。AI 会话按笔记保留；保留在纸面的内容可继续编辑。分享时可导出标准 PDF；需要可编辑副本时导出笔记包。单本笔记导出不等于完整应用备份，尤其不要假定它包含全部会话与视频附件。

## 卡住时检查

| 现象 | 下一步 |
| --- | --- |
| 点 AI 提示需要圈选 | 先用套索选内容，再检查选区预览 |
| 保存配置提示错误 | 补齐名称、HTTPS 地址、模型名和 API Key |
| 服务拒绝/没有看懂图片 | 检查模型是否支持图片、地址与模型名是否匹配、账户额度是否可用 |
| 只看到卡片，没有纸面内容 | 检查本轮是否允许写入、模型的实际工具调用及回退提示 |
| 网络等待过久 | 可本地取消；超时重试可能再次计费，先查看服务商记录 |
| 回答未流式出现 | 当前回答在生成完成后展示；不能据此推断请求没有发出 |

Android 当前读取边界与取消行为见 [AI 材料范围](AI_READ_SCOPE.md)、[请求生命周期](AI_REQUEST_LIFECYCLE.md)。问题反馈请附版本、设备、操作和错误提示，不附密钥或私人笔记。
