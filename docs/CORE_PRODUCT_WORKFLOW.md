# PadNote 核心流程

PadNote 把笔记、手写和 AI 学习交流放在同一张纸上。用户可以继续编辑页面、提问并把有用回答留在笔记里，也可以将整份纸面导出为 PDF 分享。

## 把笔记交给电脑 Agent

在当前笔记中选择“分享与交给 Agent”，查看将发送的范围，选择已配对且支持纸面上下文的电脑 Agent，再编辑任务要求或选择预设。确认后，PadNote 提交任务并打开任务详情。

纸面任务包固定包含请求、清单、可读正文、完整纸面 PDF 和两个空的成果目录。清单绑定每个输入文件的大小与 SHA-256；包大小有明确上限，超限时停止，不会静默截页或省略内容。任务只带当前笔记的材料，不包含其他笔记、知识库或凭据。提交前可以检查发送内容；取消、导出失败或目标不支持时不会发送。

## Agent 与工具

可用任务包括按用户要求继续工作、整理讲义、检查理解并出练习，以及生成讲解视频。视频风格可选清晰讲义、手写白板、类比讲解、逐步推导或一分钟复习。目标和风格提示均可编辑。

所选 Agent 决定使用的模型、语音合成和其他工具。Qwen 视频连接是可选适配器，不是通用任务的前提。只有经过验证且声明支持纸面上下文的电脑 Bridge 目标可以接收该任务；其他目标不会因出现在连接列表中而自动获得此能力。

## 数据与边界

发起任务会把发送预览中列出的当前笔记内容交给所选电脑 Agent。外部模型或工具可能按其服务条款处理数据或产生费用；用户应使用已有授权并自行检查相关设置。纸面 PDF 保留可见页面内容，但不代表手写内容已经转换成文字。任务提交成功也不代表 Agent 已完成工作。

安装与试用步骤见 [beta.10 测试指南](BETA10_TESTING.md)；源代码许可和第三方组件许可见仓库根目录的许可证与声明文件。
