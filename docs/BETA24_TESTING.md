## 检查步骤

1. **放置与取消：**选择文字笔，在纸面点击并输入几句话。点“完成”后，文字应完整显示；新建时点“取消”，占位框应消失。编辑已有文字后取消，应保留原来的内容和版式。
2. **排版失败：**尝试提交过长的内容或无法分页的表格。若应用拒绝提交，原笔记、页数和撤销历史应保持不变，输入框仍打开，完整草稿可以继续修改或取消。
3. **修正与撤销：**缩短或拆分失败内容，再点“完成”。检查全文是否显示；一次“撤销”应恢复编辑前的内容，“重做”应恢复新内容。保存并重开后，再核对文字和样式。
4. **找回草稿：**提交失败后切到后台，或返回书架，再重开同一份笔记。已保存的草稿应可继续编辑、稍后处理或丢弃；也可从笔记的更多菜单重新打开恢复入口。原文已变化时，应先提供查看和复制，让你决定如何处理。
5. **保护其他内容：**在草稿旁写几笔，再取消编辑。已有笔迹和其他文字应保留；取消恢复的新草稿，也不能移除其他操作的撤销记录。
6. **完整粘贴：**粘贴长文本，检查输入没有被悄悄截短。超出编辑容量时，应明确提示并保留输入框原有全文。若提示草稿保存失败，先复制需要保留的内容，再修正或取消。
7. **调整版式：**修改字号、拖动文字或调整框宽。能完整排版时应正常生效；无法完成时，应提示原因并保留原来的文字和布局。
