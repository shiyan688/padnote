# 视频风格提示词

这些是可编辑的任务提示，不指定模型、配音服务或制作工具。由所选电脑 Agent 根据用户配置执行。以当前纸面和学习交流为依据，先给出分镜供审阅；不编造材料没有支持的结论。

| 风格 | 提示词 |
| --- | --- |
| 清晰讲义 | 用清晰的讲义式画面讲解。每个画面聚焦一个概念，标题简短，公式、图和解释放在一起。例题按步骤展开，减少装饰和套话。 |
| 手写白板 | 像老师在白板上边写边讲。从问题开始，逐步画出图、写出关键公式和批注，让观看者看清每一步怎样产生。避免一次铺满整张白板。 |
| 类比讲解 | 先用一个贴近日常的类比建立直觉，再回到材料中的准确概念。明确指出类比适用的范围和容易误解的地方。 |
| 逐步推导 | 围绕一个问题展开完整推导。每一步说明使用的前提、公式或变换，突出本步变化的符号，不跳过影响理解的步骤。 |
| 一分钟复习 | 做一个约一分钟的复习视频，选出最值得记住的三个要点，指出一个常见误区，最后留一道简短自测题。保留必要条件和单位，不为缩短时长改变结论。 |

视频只是通用纸面任务的一种用途。`note.work.v1` 中的风格提示应写入可编辑的目标或 `brief.style_prompt`；不要将这些名字塞进现有只允许 `clean-academic` 的 `video.explain.v1` 字段。
