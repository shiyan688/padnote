# 支持范围与反馈

PadNote 正在公开预览。判断能力是否可用，应看具体安装包和完整流程证据，不能只看源码中是否出现了某个 Agent 名称。

截至 2026-09-24，公开 Android 版本为 [0.18.0-beta.6](https://github.com/shiyan688/padnote/releases/tag/v0.18.0-beta.6)。beta.7 的电脑连接助手和客户端包仍为本地预览，后续源码修改还在验证。iPad 已有 Xcode 工程和无签名构建，尚无面向普通用户的可安装分发包。

| 能力 / 环境 | 有什么证据 | 尚缺什么 |
| --- | --- | --- |
| Android，最低 Android 7 / API 24 | 编译目标 API 35；API 35 ARM 平板模拟器已运行书架、排版、PDF 与连接存储测试 | 最低版本原生回归、真实触笔、相机、长时间使用、升级迁移 |
| iPad，最低 iPadOS 17 | Xcode 工程、iPad 模拟器测试、arm64 无签名构建 | 最低系统回归、Apple Pencil、签名安装与分发 |
| 模型直连 / 两阶段 | 客户端协议及本地假服务回归 | 逐个提供商与模型版本的实际验证；不承诺所有兼容 API 行为一致 |
| Hermes + 连接助手 | 多实例和逐设备配对、任务、审批、停止、文件校验的本地协议测试 | Windows/WSL2 网络与现有真实 Hermes 全流程 |
| OpenClaw | 发现、连接诊断与设置引导 | 原生设备配对和任务执行适配 |
| Codex | 接入评估待完成 | 可供用户使用的适配器 |
| 笔记生成视频 | 任务包、worker 协议、离线样例及校验器 | 应用内分镜修订审批、持久执行、完整结果回到笔记 |

模拟器里发现的问题和新修复的证据记录在 [TODO 执行账本](TODO_EXECUTION.md)；此表不把尚未回归的修改提升为已发布能力。HarmonyOS 原型不在当前安装支持范围内。Android / iPad 保留一致的数据和任务契约，优先验证一条完整链路，再扩大兼容承诺。

普通用户可先在新建笔记中试写、圈选和导出；开发者从仓库的本地夹具与协议测试开始。连接真实电脑之前，先用“只回复连接成功”的小任务检查身份和往返，再提交自己的材料。

## 自愿体验反馈

欢迎用 [问题模板](https://github.com/shiyan688/padnote/issues/new/choose)记录：想完成的事、首次成功用了几步、需要帮助的地方、重开或恢复是否成功、失败发生在哪个阶段。可以只给脱敏文字描述，无需上传私人笔记或教材。

这是一份自愿反馈流程，不要求开启行为追踪。当前没有默认上传笔记或统计使用行为的后台。维护者根据可复现问题、数据安全和完整流程的阻碍安排修复；不承诺固定响应时限或长期维护每个旧 beta。停止支持某种协议或数据格式前，应给出迁移与保留原件的办法。
