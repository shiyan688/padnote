# beta.19 使用与反馈

这一版集中改进文字输入和电脑 Agent 连接，不改变已有笔记的格式。

- 新建文字默认“正文”，支持 Markdown；公式仍有独立入口。旧文字保留原格式。
- 检测连接会区分“电脑助手可达”与“Hermes 接口可用”。电脑端显示最近检测时间，过期结果会提示重新检测。
- Hermes 暂时不可用时保留配对和历史任务，不要求重新扫码；检查电脑上的服务与凭据后再次检测。
- 第一条任务等待 Hermes 时，另一条任务可以独立获得收据。最多同时进行两条上游提交；队列满时明确提示未联系 Hermes。
- “已送达电脑”表示助手保存了任务，不表示 Agent 已执行完成。结果未知时不会自动重发。

## 安装

Android 使用 Release 的 APK 覆盖安装，保留原包签名和资料；不要通过卸载或清除数据排查问题。系统要求设备所有者认证时，由本人完成。Windows 提供 Setup 与便携包。iPad 提供可编译源码，暂未提供签名 IPA。

文件完整性可对照同一 Release 的 `SHA256SUMS.txt`。升级前建议从应用的“整库”入口另存资料库备份。

## 建议试用顺序

1. 用一条测试笔记输入正文和公式，缩放、返回书架再重开，确认内容和格式一致；导出 PDF 检查文字与最后一页。
2. 在电脑助手添加或选择 Hermes，点击“检测 Agent 接口”；平板重新检测对应连接，核对目标名称与状态。
3. 发送一条无敏感内容的小任务，返回笔记，再从电脑任务查看结果。收据、Agent 运行编号和完成结果分别核对。
4. 有多个连接时，确认发送前选的是预期电脑和 Agent。切换默认连接不会将旧任务转发到新目标。

反馈请包含应用版本、设备/系统、操作步骤、实际提示和预期结果。可附合成笔记截图或应用提供的诊断；不要附 API Key、配对令牌或私人笔记。任务结果未知时先保留记录，不新建相同任务绕过提示。

## 开发验证边界

候选已通过桌面自动回归与 iPad 应用/测试包编译；Android 的 JVM、lint 和 APK 构建结果以本次 Release 说明为准。合成界面预览、Mock Agent 测试、编译成功与真实 Agent 执行是不同证据。具体设备、签名安装和真实任务问题仍按实际反馈继续修复。
