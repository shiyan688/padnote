# Hermes 请求期限与撤销验证

2026-09-24，本地源码检查点 `assistant-hermes-deadline-r2`。这批处理电脑助手至 Hermes 的请求，不等于 Windows/WSL2 的实际安装与联网验收。

## 行为

一次请求使用共同的单调时钟期限，覆盖解析地址、连接、TLS、响应头和正文读取。缓慢但持续返回字节不会不断延长等待。正文按块读取，累计最多 2 MiB；异常长度、截断或无效 JSON 不会当作成功结果。

POST 可能已经发送时，响应中断或损坏会保留“结果未知”。停止一个尚未拿到上游 ID 的任务不会重新提交任务；用户可以到电脑核对，再决定是否重试。显式提交重试沿用已保存的幂等身份，但仍受上游保留期约束。

设备撤销先持久化。已经排队的操作在实际执行前重新认证，不能在撤销后继续向 Hermes 发送请求。已经被 Hermes 接受的任务不会因为设备凭据撤销而自动停止。

保留系统 TLS 验证与 SNI，禁用环境代理和重定向。错误消息不包含上游正文、请求内容或密钥。操作系统 DNS 调用不能强制取消，因此最多保留两个尚未结束的解析线程；它们只持有地址与端口。此上限不是对整个进程内存或公网拒绝服务的保证。

## 入站请求独立检查点

`assistant-http-deadline-r3` 已由根代理独立验证：32 个源码/测试文件匹配，46 项助手测试与 7 项 HTTP 集成通过。其中9项覆盖慢客户端、长度校验、到期竞态、线程启动失败和断开时文件清理；证据 `dist/todo-review/assistant-http-deadline-r3-verification.json`。

请求头与正文从接受连接起共享20秒输入期限，收到完整正文后结束这个期限，正常业务处理不受其误伤。JSON响应另有20秒写出期限；文件下载按固定开销加192 KiB/s计算总时间，最多10分钟，15秒停顿限制仍保留。下载预算不随每块数据到达而延长。当前12 MiB输入在20秒内需约615 KiB/s，较弱网络下需减小材料；弱网上传可用性仍是后续实测项。

超时已触发但正文恰在缓冲区时，仍拒绝进入业务。Admin与API的POST共用长度校验，拒绝重复/非法长度、Transfer-Encoding及短读。超时、客户端断开和线程启动失败会释放连接资源；artifact文件从准备响应头前即进入关闭保护。

r1的42+7通过后，复查发现两个清理/竞态缺口，已在r2修正。r2根代理复跑遇到旧Codex测试子进程过早退出的竞态；r3只稳定该fixture，并继续断言重复审批不发送，未放宽生产审批。所有历史失败日志保留。这些措施约束本机助手资源，不提供公网DDoS保证。
