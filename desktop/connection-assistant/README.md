# PadNote 电脑连接助手

把平板上的任务交给电脑里的 Hermes，并在 PadNote 查看进度、处理审批、取回文件。助手运行在你自己的电脑上；不需要部署 PadNote 服务器。

这是配合 PadNote **0.18.0-beta.7** 的预览版本。Android 与 iPad 使用同一配对协议；此前发布的 beta.6 不具备这个配对入口。

## Windows / WSL2

适合已经能在 WSL 终端中使用 Hermes 的电脑。沿用现有安装和模型配置。

1. 解压整个目录，运行 **Start-PadNote.cmd**，选择安装 Hermes 的 WSL 发行版。WSL 内需有 Python 3.10 或更新版本，无需安装额外 Python 包。
2. 在打开的电脑管理页中选择检测到的 Hermes 配置，点击“使用这套配置”。助手只在你选择后解析该文件的 API Server 设置，不会执行配置文件或覆盖内容。未自动找到的实例也可手动添加。
3. 检查接口。Hermes 终端能对话但未启用 API Server 时，按照管理页和 [连接教程](../../docs/HERMES_CONNECTION.md) 补充设置并重启 Gateway；随后回助手刷新发现，再次点击“使用这套配置”，然后检测实例。默认本机接口是 `http://127.0.0.1:8642`。
4. Windows 和平板连接同一个 Tailscale 私网。在 Windows PowerShell 先查看 `tailscale serve status`；确认没有占用同一入口的其他服务后，运行：

   ```powershell
   tailscale serve --bg --https=443 http://127.0.0.1:8765
   ```

5. 在助手里选实例，填入 Serve 输出的 HTTPS 地址并生成二维码。PadNote 中扫码或粘贴配对内容，核对地址后申请，回电脑点击“刷新待批准设备”，核对后批准。

电脑管理页默认为 `http://127.0.0.1:8766`，平板设备接口使用 `127.0.0.1:8765`。**Serve 只转发 8765。** 管理页不能提供给远程设备。

助手和 Hermes 应运行在同一个 WSL 发行版中，任务文件才能直接供 Hermes 使用。WSL、Hermes、助手和 Tailscale 都需保持运行；电脑休眠后不会继续响应平板。

## macOS / Linux

在运行 Hermes 的同一台电脑解压，macOS 运行 `Start-PadNote.command`，Linux 运行 `start-padnote.sh`。需要 Python 3.10 或更新版本。随后按同样的管理页流程操作。

也可从终端运行：

```sh
python3 start.py
```

`--no-browser` 不自动打开浏览器；`--state-dir` 可指定独立数据目录。默认数据目录为 `~/.local/share/padnote-connection-assistant`。两个端口可分别用 `--admin-port`、`--api-port` 指定，始终仅监听本机回环。

同一个数据目录一次只能由一个助手进程使用；通过符号链接指向同一目录也视为同一个目录。第二个进程会在读取状态前退出并提示先关闭正在运行的助手。助手使用操作系统文件锁，正常退出或进程被终止后会自动释放；目录中的 `.owner.lock` 是固定锁入口，请勿删除，也无需用它判断进程是否仍在运行。助手不会因锁冲突删除状态、配对或凭据。

## 多个 Agent

同一个助手可以登记多个 Hermes 实例，每个实例单独配对。另一台电脑运行自己的助手，再在平板添加连接即可。实例名称可以相同，授权仍按独立身份隔离；建议使用能区分电脑和用途的名称。

每次配对产生独立的设备凭据。Hermes 的长期 API 密钥不发给平板。电脑端可以撤销某个设备对某个实例的访问，不影响其他连接。平板删除连接不等于撤销授权，也不会自动停止电脑上的任务。

从已选择的配置文件加载的凭据，在重启时会按记录复核。手动输入的密钥只保留在当前进程，重启后需再次填写同一密钥。API 地址或密钥改变后，助手会停用旧实例；重新选择配置或填写新密钥会建立新身份，需要重新配对。旧授权和旧任务不能自动继承新身份。

## 先验证一次小任务

在 PadNote 中对新连接发送“只回复：连接成功，不要操作文件”。收到结果后，再尝试笔记任务包。任务结果页保留任务来源；中断后通过原任务查询或重试，不要反复新建相同任务。

任务包保留现有 `video.explain.v1` 文件格式，并绑定本次选定笔记的版本。首阶段先生成分镜供审阅。生成完整视频还需要 Hermes 具备相应 Skill、TTS 和渲染工具；助手本身不提供这些能力，也不把文字回复当作视频生成成功。

## 当前范围

- 支持 Hermes 配对、文字及任务包提交、状态查询、一次性审批、停止、产物下载与逐连接撤销。
- 使用状态轮询；没有承诺实时逐字输出。已记录的任务和终态可在助手重启后保留。
- OpenClaw 目前只做发现与设置引导，任务协议尚未接入。Codex 尚未接入。
- 文件传输限制在当前任务目录，校验路径、大小和摘要；这不等于 Hermes 的工具执行已处于操作系统沙箱。Hermes 仍使用其自身的权限和审批配置。
- Windows / WSL2 网络、扫码相机和真实 Hermes 任务需要在实际设备上验收。本地假服务测试不代替真实电脑测试。

开发协议见 [CONNECTION_ASSISTANT_PROTOCOL.md](../../docs/CONNECTION_ASSISTANT_PROTOCOL.md)，测试范围见 [AGENT_CONNECTION_QA.md](../../docs/AGENT_CONNECTION_QA.md)。配对二维码在本机生成，第三方许可保存在 `vendor/`。
