# 看不见的频率：为什么一个信号可以有两种坐标？

## 受众与目标
大学理工科入门到进阶；已知三角函数、积分、复数和欧拉公式。
目标：把傅里叶系数理解成与参考振荡的相关程度，区分信号、频谱与重建。
短视频只讲有限周期信号的傅里叶级数直觉，再指出它与傅里叶变换的联系，不声称覆盖完整理论。

## 一个能精确拆开的信号
时间 t 以秒计，观察区间 [0,1]，将信号按 1 秒为周期延拓：
\[
x(t)=\sin(2\pi t)+\tfrac12\sin(6\pi t).
\]
它是 1 Hz 正弦波与振幅为其一半的 3 Hz 正弦波相加。复合曲线的高度等于同一时刻两个分量高度的和。
不能仅凭复合曲线里“看见几个峰”来确定频率分量。

## 用投影找出分量
对正整数 k，定义正弦投影系数：
\[
b_k=2\int_0^1 x(t)\sin(2\pi kt)\,dt.
\]
不同整数频率的正弦在这个区间正交：相乘后正负面积抵消；相同频率相乘得到平方，积分为 1/2。
所以 b₁=1，b₃=1/2，其余正整数 k 对应 b_k=0。
这个例子没有余弦项。一般周期信号还需要直流项与余弦项，不能把这一个例子的公式当成所有信号的完整表示。

## 图像应该解释什么
先同时显示两个分量与逐点相加后的曲线；横轴统一为时间。
再显示参考频率 k=1 与 k=2 的乘积及正负面积，让“匹配”和“抵消”可见。
最后显示单边正弦系数图：横轴 k（对应 Hz），在 1 和 3 处高度为 1 和 0.5。不要把它标成通用的双边复频谱。
将系数乘回各自基函数再相加，恢复原信号。

## 与更一般理论的联系
一般傅里叶变换把合适的非周期信号表示在连续频率坐标下；常用约定为：
\[
X(f)=\int_{-\infty}^{\infty}x(t)e^{-i2\pi ft}\,dt.
\]
适用条件和逆变换另讲。前面的周期正弦例子应使用级数来解释，不能直接把它当成绝对可积函数套入这个积分。

## 自测
把 3 Hz 分量的系数从 1/2 改为 1/4：它的频率位置不变，系数高度减半。
